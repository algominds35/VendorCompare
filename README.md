# VendorCompare

**AI-Powered Vendor Quote Comparison Tool**

## What It Does

Upload multiple vendor quotes → AI extracts pricing → Get instant comparison table

## Features

✅ Drag & drop file upload  
✅ Supports PDF, Excel, CSV, Images  
✅ Clean, professional UI  
✅ Real-time file management  
✅ Ready for AI integration

## Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool
- **Tailwind CSS v3** - Styling
- **OpenAI API** - Backend (coming soon)

## Run Locally

```bash
npm install
npm run dev
```

Visit: http://localhost:5173

## Deploy

Deployed on Vercel
